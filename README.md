# Peña · Grupo Misionero Espíritu Santo

Página para que los misioneros carguen a las personas que les compraron entrada a la peña (lista de ingreso).
Los datos viven en el Google Sheet "Pena_Entradas"; el código del servidor (Apps Script) está en `apps-script/Codigo.gs`.

- Misioneros: https://misionespiritusanto.github.io/Pena/
- Coordinadores (puerta, pagos, resumen): https://misionespiritusanto.github.io/Pena/#admin

## Rifa Navideña 2026 (carpeta `rifa/`)

Página para que los misioneros anoten cada rifa que venden (comprador, celular y cantidad). La página asigna los números y arma el mensaje de WhatsApp para el comprador.
Los datos viven en el Google Sheet "Rifa_Navideña"; el código del servidor está en `rifa/apps-script/Codigo.gs`.

- Misioneros: https://misionespiritusanto.github.io/Pena/rifa/
- Coordinadores (pagos, ventas, resumen, sorteo): https://misionespiritusanto.github.io/Pena/rifa/#admin
